Gen AI Job Preparation

This project is designed to simulate a real-world product where users can upload their resumes, analyze job descriptions, detect skill gaps, and generate AI-powered interview questions and ATS-optimized resumes.


Features

🔐 User Authentication (Login/Register)
🛡️ Protected Routes
🤖 AI Interview Practice
📄 Resume PDF Generation
📊 User Dashboard
🎯 Personalized Job Preparation
📱 Responsive UI


🛠 Tech Stack Used

Frontend: React.js
Backend: Node.js + Express.js
Authentication: JWT + Token Blacklisting
AI: Gemini API
PDF Generation: Puppeteer
